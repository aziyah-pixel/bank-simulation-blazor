# 🏦 Bank Simulation Web App

A simple bank simulation application built with **C# and Blazor** as a learning project to explore web application development using the .NET ecosystem.

This project is a web-based development of a previous console-based bank simulation program, with an interactive user interface for performing basic banking operations.

## 🎯 Project Objectives

- Learn how to build interactive web applications using Blazor.
- Apply C# programming concepts to web development.
- Understand component-based UI development.
- Practice implementing basic banking logic in a web application.

## ✨ Planned Features

- **Account Information** — Display basic account details.
- **Check Balance** — View the current account balance.
- **Deposit** — Simulate depositing money into an account.
- **Withdraw** — Simulate withdrawing money from an account.
- **Transaction Feedback** — Display messages for successful or unsuccessful operations.

*Note: Features will be updated as the project develops.*

## 🛠️ Tech Stack

- **C#** — Application logic.
- **Blazor** — Interactive web user interface.
- **.NET** — Application development platform.
- **HTML & CSS** — Page structure and styling.

## 🚀 Getting Started

### Prerequisites

- .NET SDK compatible with the project.
- Visual Studio or Visual Studio Code.
- A web browser.

### Run Locally

1. Clone this repository:

   ```bash
   git clone https://github.com/YOUR-USERNAME/bank-simulation-blazor.git
   ```

2. Navigate to the project directory:

   ```bash
   cd bank-simulation-blazor
   ```

3. Restore dependencies:

   ```bash
   dotnet restore
   ```

4. Run the application from the directory containing the project file:

   ```bash
   dotnet run
   ```

5. Open the local URL displayed in the terminal.
